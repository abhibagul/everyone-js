A comprehensive accessibility widget that enhances web accessibility with a simple integration.

## Overview

EveryoneJS is a lightweight, customizable accessibility solution that helps websites comply with accessibility standards and provides users with various tools to adjust content according to their needs. The widget adds a floating button to your website that opens a panel with multiple accessibility options.

## Features

### Accessibility Profiles

- **Seizure Safe Profile**: Eliminates flashes and reduces color
- **Vision Impaired Profile**: Enhances website visuals
- **ADHD Friendly Profile**: Reduces distractions and improves focus
- **Cognitive Disability Profile**: Assists with reading and focusing
- **Keyboard Navigation**: Optimizes for keyboard-only users
- **Screen Reader**: Optimizes for screen reader users

### Content Adjustments

- Content scaling
- Readable font
- Highlight titles and links
- Text alignment options
- Font size adjustment
- Line height adjustment
- Letter spacing adjustment
- Text magnifier
- Reading guide
- Reading mask

### Color Adjustments

- Dark contrast
- Light contrast
- High contrast
- High saturation
- Monochrome
- Low saturation
- Custom text, title, and background colors

### Orientation Tools

- Mute sounds
- Hide images
- Reading guide
- Reading mask
- Stop animations
- Highlight focus and hover
- Big cursor options (black/white)

## Installation

### Basic Installation

Add the following script tag to your website's HTML:

```html
<script src="https://cdn.example.com/everyone.min.js"></script>
```

## Configuration

You can customize EveryoneJS by adding a configuration object before loading the script:

```html
<script>
  window.everyoneJSConfig = {
    buttonSize: "50px",
    buttonColor: "#007bff",
    iconColor: "#ffffff",
  };
</script>
<script src="https://cdn.example.com/everyone.min.js"></script>
```

## Browser Support

EveryoneJS works with all modern browsers:

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Opera (latest)
- IE11 (with polyfills)
